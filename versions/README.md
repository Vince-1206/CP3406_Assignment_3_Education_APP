\# VocabQuest Version History



This folder preserves the five development milestones of the VocabQuest educational Android application.



\## V1 — Compose Foundation



\- Initial Kotlin and Jetpack Compose project

\- Landing, Activity, Progress and Settings screens

\- Basic navigation, ViewModel and Repository structure

\- Starter vocabulary quiz



\## V2 — Learning and Quiz Improvement



\- Expanded the vocabulary lesson to 10 words

\- Added a separate learning screen

\- Quiz definitions remain hidden until an answer is submitted

\- Added correct and incorrect answer feedback



\## V3 — Connected Learning Flow



\- Connected Home → Learning → Quiz → Results

\- Removed the separate Quiz bottom-navigation button

\- Bottom navigation changed to Home, Progress and Settings

\- Added clear Home and Progress actions



\## V4 — Room Persistence



\- Added a Room local database

\- Quiz results remain after restarting the app

\- Home and Progress screens use real saved data

\- Added average, latest and best-score calculations



\## V5 — Dictionary API



\- Added Retrofit networking

\- Connected to the Free Dictionary API

\- Added online definitions, pronunciation and parts of speech

\- Added loading, retry, caching and offline fallback behaviour

\- V5 is the final working application stored at the repository root
